Savage Wind with a Cheats tab (0.3.1-alpha.3)

1. Extract this "Savage Wind Cheats" folder anywhere, for example next to your Savage Wind folder.
2. If your Savage Wind folder is not in Downloads\Games\SavageWind-0.3.1-alpha.3-windows\Savage Wind,
   open play-with-cheats.bat in Notepad and fix the GAME_FOLDER line.
3. Double-click play-with-cheats.bat.
4. In game press F1 (or Back + Start on a controller) and open the Cheats tab.

Your Savage Wind folder is used as it is: nothing there is replaced. To play without cheats, start the
original savagewind.exe as usual. Cheats start off every time.
